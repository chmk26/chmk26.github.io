## Intro
로보틱스 공부를 위해 가장 필수적인 ROS2 설치와 기본 세팅을 진행하고자 한다. 노트북에 새로 Ubuntu 26.04 버전을 설치한 만큼, ROS2 역시 최신 버전이 Lyrical Luth를 설치하고자 한다.

우분투와 ROS 버전 호환표를 아래와 같이 정리해보았다.

| Ubuntu                 | ROS/ROS2          |
| ---------------------- | ----------------- |
| Ubuntu 18.04 (Bionic)  | ROS Melodic       |
| Ubuntu 20.04 (Focal)   | ROS Noetic        |
| Ubuntu 22.04 (Jammy)   | ROS2 Humble       |
| Ubuntu 24.04 (Noble)   | ROS2 Jazzy        |
| Ubuntu 26.04 (Raccoon) | ROS2 Lyrical Luth |

ROS2 Lyrical 설치는 아래의 공식 문서를 따라 진행되었다.
- https://docs.ros.org/en/lyrical/index.html
